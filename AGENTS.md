# Agent guidance

Maintainer repository for a public LaTeX Dev Container image.
Skills live in `.agents/skills/`. `.claude/skills` is a **symlink**. Catalog: [`.agents/skills/README.md`](.agents/skills/README.md).

If the path is under `.agents/context/`, load `nested-context-work` first. Local checks are `make lint`, `make check-docs`, and `make pre-commit`.
